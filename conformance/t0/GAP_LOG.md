# T0 · the gap log (the dry-run's real deliverable)

> Every question, blocker, and ambiguity the executor hits, written
> here, timestamped, verbatim. **Each entry is a spec bug** — an
> under-specified law, a missing fixture, an undefined term. The
> dry-run measures the spec, never the developer.

## How to write an entry

```
### YYYY-MM-DD HH:MM · <one-line summary>
- **where**: the spec section / fixture / term at fault
- **what happened**: what you tried · what you expected · what you got
- **class**: question · blocker · ambiguity
- **resolution** (filled by the maintainers): the spec fix shipped
  (NEP / chapter / fixture) or « works as specified, teaching added »
```
